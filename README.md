# PathForge AI 🚀

PathForge AI is an AI-powered career mentorship platform built using the MERN stack and OpenAI APIs. The platform helps students and beginners explore career paths, generate personalized learning roadmaps, prepare for interviews, and interact with an AI mentor.

---

## ✨ Features

- 🔐 User Authentication
- 🤖 AI Career Recommendations
- 🛣️ Personalized Roadmap Generation
- 💬 AI Mentor Chatbot
- 🎯 Interview Preparation
- 📚 Saved Chat & Roadmap History
- 🌙 Modern Responsive UI
- ☁️ Cloud Deployment

---

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/pathforge-ai.git
```

---

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

---

### Backend Setup

```bash
cd server
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside `server/`

```env
PORT=5000
MONGO_URI=your_mongodb_uri
OPENAI_API_KEY=your_openai_api_key
```
